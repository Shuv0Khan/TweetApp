TweetApp

## Configuration

Credentials are not stored in the code. Copy the example files and fill in your own values:

- `.env.example` to `.env` (Twitter, Perspective API, Neo4j and alert-email settings)
- `scraping/.env.example` to `scraping/.env` (Scweet login)
- `twitter_api_keys.example.yaml` to `twitter_api_keys.yaml` (searchtweets credentials)

All three real files are git-ignored. You can also set the same names as environment variables.
